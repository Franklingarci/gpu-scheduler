# Real-hardware GPU monitoring (scheduler/gpu.py :: NVMLGPUMonitor).
#

# package anyway.
#

# wrapper, so it only fails at nvmlInit() when there is no libnvidia-ml to
# find. That means the simulator still runs anywhere.
